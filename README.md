# StudyPulse AI - Academic Suite

## Overview
StudyPulse AI is a universal academic study suite designed for students like Muhammad Tayyab Zafar to streamline learning, solve academic problems, and manage study schedules in one place.

## Live Deployed URL
* **Live App:** https://studyplus-ai.vercel.app

## Features
* **Lecture Transcriber:** Summarizes audio and notes into concise study notes.
* **Socratic Solver:** Vision-based problem solver for academic equations and questions.
* **Flashcards & Quiz:** AI-powered deck generation for active recall.
* **Study Planner:** Spaced-repetition revision schedule manager.
* **AI Socratic Tutor:** Interactive AI mentor chat for conceptual clarity.
* **Focus Timer:** Pomodoro sessions to maintain study focus.

## AI Implementation & System Prompt
The application leverages the **Google Gemini API** to process text, images, and audio transcriptions dynamically. The system prompts instruct Gemini to act as an advanced educational assistant, breaking down complex mathematics and physics problem sets step-by-step.

## Tech Stack
* **Frontend:** React, Vite, Tailwind CSS
* **Backend / State:** Local server environments & Supabase integration
* **AI Model:** Google Gemini API
